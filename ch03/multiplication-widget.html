One product, two views

A: 2 × 3
4−35−267
v: 3 × 1
2−13
=
Av: 2 × 1
2611

1. Check the shape

A has three columns, so v needs three entries. A has two rows, so the result has two entries.

Each output will be a sum of three products.

2. Use the first row

Multiply the entries 4, −3, 5 by the corresponding entries of v, then add.

The result is the first output entry, 26. Write the first row vertically: its dot product with v gives this same calculation. Both vectors are in R³.

3. Use the second row

Do the same with −2, 6, 7 to get the second output entry, 11. Again, writing the row vertically gives a vector in R³ whose dot product with v is 11.

One row → one output entry.

4. Follow the first column

In both rows, the first matrix entry is multiplied by the first input entry, 2.

Together these contributions are 2 times column 1.

5. Follow the other columns

The second input entry, −1, multiplies column 2. The third input entry, 3, multiplies column 3.

One input entry → one column weight.

6. Add the column contributions

The three scaled columns add to the same result. Matrix-vector multiplication is a linear combination of the columns!

Rows compute the output one entry at a time. Columns build the whole output vector.
