# Repository instructions

- Be brief in user-facing updates.
- Use sentence case for titles and headings (for example, "Like this" rather than "Like This").
- Use Plotly for every plot; do not add Matplotlib, Seaborn, TikZ, or another plotting library.
- Give every plot a white background and Palatino text.
- Use categorical colors in this order: `#3d81f6`, `orange`, `#d81a60`.
- Render 2D plots as PNG unless the user explicitly requests interactivity.
- Keep 3D plots interactive so readers can drag and rotate them.
- Add the `remove-input` cell tag to every visualization or visualization-helper cell.
- After changing a plot, execute its notebook and refresh the stored output.
